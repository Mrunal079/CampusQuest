# Campus Quest: Find Your Next Move

A Python pixel-art role-playing game about navigating university life,
with eight chapters, branching conversations and three optional mini-games.

## Download and run

1. Open CampusQuest.zip in this repository and download the raw file.
2. Extract it.
3. Open a terminal inside the extracted CampusQuest folder.
4. Install dependencies:

   python3 -m pip install -r requirements.txt

5. Start the game:

   python3 main.py

Requires Python 3.12, pygame-ce and Pillow.
On Windows, replace python3 with py -3.12.
